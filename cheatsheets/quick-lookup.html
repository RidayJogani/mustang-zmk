1. Brackets & Quotes

Brackets sit symmetrically on the inner columns (G/H and B/N).

(   )Hold LT2 + G / H
[   ]Hold LT2 + B / N
{   }Hold LT2 + RT2 (Shift) + B / N
<   >Hold RT2 (Shift) + , / . (Base)
'   "Outer right home (') / +Shift (")
`Hold LT2 + / (Right bottom pinky)

- + %Hold LT2 + J / K / ;
_ =Hold LT2 + M / ,
| : ?Hold RT2 (Shift) + \ / ; / /

3. Navigation & Editing

Outer pinky columns mirror on Layer 2: HOME/END & PG_UP/PG_DN.

← ↓ ↑ →Hold RT3 + H J K L
HOME / ENDHold LT2 + TAB / ' (Outer home)
PG_UP / PG_DNHold LT2 + DEL / \ (Outer bottom)
PSCRNHold LT2 + L
TAB / DELLeft outer Home / Bottom (Base)
ESC / BSPCTap LT3 (ESC) · Tap RT4 (BSPC)

4. Mouse & Scroll

Left hand clicks on home row; right hand moves or scrolls on H J K L.

Move CursorHold LT1 + H J K L
Scroll ModeHold LT1 + RT3 + H J K L
Left ClickHold LT1 + F
Right ClickHold LT1 + G
Middle ClickHold LT1 + D
Back / ForwardHold LT1 + A (MB4) / ; (MB5)

5. Function Keys (F1–F12)

All 12 F-keys flow left-to-right across Layer 1 (LT1).

F1Hold LT1 + TAB (Left outer home)
F2 – F6Hold LT1 + Q W E R T
F7 – F11Hold LT1 + Y U I O P
F12Hold LT1 + ' (Right outer home)
